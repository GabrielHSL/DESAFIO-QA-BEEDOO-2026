# DESAFIO-QA-BEEDOO-2026
Este repositório contém a análise e execução de testes para o desafio técnico de QA da Beedoo.


## Análise inicial da aplicação

A aplicação analisada consiste em um sistema simples de gerenciamento de cursos.

O sistema permite:

-Cadastro de novos cursos

-Visualização dos cursos cadastrados



##Fluxos identificados

Fluxos principais:

Fluxo 1 — Cadastro de curso

Usuário:

Acessa a tela de cadastro

Preenche os campos

Clica em Cadastrar curso

Resultado esperado:

Curso criado com sucesso.

Fluxo 2 — Listagem de cursos

Usuário:

Acessa a tela de listagem

Visualiza cursos cadastrados


##Pontos críticos para teste


Durante a análise inicial foram identificados alguns pontos críticos para testes:

Validação dos campos do formulário

Consistência das datas do curso

Validação do número de vagas

Comportamento da aplicação diante de entradas inválidas

Exibição correta dos cursos cadastrados


##Estratégia de testes


A estratégia de testes foi baseada em testes funcionais exploratórios, considerando:

Fluxos principais (happy path)

Cenários negativos

Validações de campos

Casos de borda (boundary testing)

Possíveis falhas de segurança e usabilidade
